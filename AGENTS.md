# Overarch Overview
* open platform for architecture modeling, analysis and generation.
* provides a data model for the holistic description of software systems and enterprises with their system landscapes
* opening multiple use cases on the model data
* written in Clojure.

# Folder Structure
/src - overarch source code
/test - overarch tests
/resources - overarch classpath resources
/templates - overarch templates and generation config
/models - overarch model and view definitions for the overarch project
/examples - overarch example models
