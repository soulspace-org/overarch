# Agent Support
The agent support allows AI agents to interact with the project model and follow the defined rules.

# Setup
The agent supports Claude and GitHub agents (maybe others too).

For Claude, use `CLAUDE.md` and the `.claude` folder. For GitHub, use `AGENTS.md` and the `.github` folder.

Copy the `AGENTS-template.md` into the project's `AGENTS.md` or `CLAUDE.md` and fill it in for your project.

Copy the `skills` and `references` folder to `.claude` or `.github`.
