
# Domain Specific Language (Non-goal)
## Description
Overarch shall not a implement a domain specific language for architecture modeling.


## Documentation
Models should be specified in plain clojure data structures and not in
         a domain specific language. This allows to use the full power of
         clojure for model specification and avoids the need to learn a new
         language. The model can be stored in a text file in edn format which
         is a standard format for clojure data structures and can be read by
         other tools as well. No special parser is needed to read the model and
         no special editor is needed to edit the model.
