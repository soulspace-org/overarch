
# Fancy UI (Non-goal)
## Description
Overarch shall not provide a fancy UI.


## Documentation
Overarch leverages the power of existing editors and IDEs for editing
         the model and generating artifacts. It does not provide a fancy UI for
         editing the model or generating artifacts. The focus is on the model
         and the generation of artifacts, not on the UI.
