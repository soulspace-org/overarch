
# deployment-architecture-view (Schema)
## Description
The deployment architecture view is a static architectural view.
          It shows the deployment of a system with the infrastructure modelled
          as nodes and the container instances and artifacts of the system
          deployed in these nodes. It also shows the architectural relationships
          between the deployed container instances and artifacts.
